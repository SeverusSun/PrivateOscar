# Private_Oscar（私人奥斯卡）

基于你的豆瓣书影音档案，举办一场完全属于你自己的电影奥斯卡，生成可以分享的专属海报，并在主动上传后与「人人奥斯卡」社区交流。

A personal "Academy Awards" website: import your Douban movie archive, nominate winners, rank your Top movies, export shareable posters, and optionally publish them to a community gallery.

**本地优先：影库和评选进度默认只保存在浏览器 localStorage，不会自动上传。只有主动上传的海报、用户名、评选结果及颁奖词会公开展示，豆瓣 UID 不公开展示。**

## 界面设计

- **整体风格**：仿豆瓣的绿色基调（豆瓣绿 `#007722`），衬线字体，简洁卡片式布局。
- **海报配色**：获奖烫金 `#c9a227`、提名墨绿 `#1b4332`、豆瓣评分橙 `#e09015`；Top 榜前三名使用金银铜三色。
- **交互细节**：提示消息从底部浮出；奖项/名次支持拖拽排序；上传冲突时可选择覆盖并清零点赞，或上传独立结果。

## 社区功能与数据规则

- **账号与会话**：上传、覆盖、点赞和删除需要网站账号。账号可绑定当前豆瓣 UID；密码经 bcrypt 哈希保存，登录使用 HttpOnly Cookie 会话。
- **导出后主动上传**：三类 JPEG 始终先下载到本地，再弹出上传窗口。未登录、取消或上传失败都不会影响本地图片，也不会自动公开本地影库。
- **重复评选处理**：按豆瓣 UID、评选模式、范围和 Top 类别检测已有结果。覆盖前明确提示点赞不可恢复；确认覆盖后，旧评选关联的所有海报点赞均清零，其他类型图片可保留但其点赞同样清零。选择「上传唯一评选结果」则另建独立评选并保留旧结果。
- **人人奥斯卡**：支持图片类型、评选范围、Top 类别、我的上传、点赞量和上传时间筛选排序，以及分页、原图下载、UUID 复制和删除自己的评选。每个账号对每张图片最多计一次点赞。
- **众人所评**：奥斯卡只统计最终获奖，Top 榜统计所有入榜名次；传统、可选、自定义奖项以及每个预设、自定义 Top 类别均独立分组，按次数降序展示前十名，同次数按片名排序。
- **站点统计**：展示匿名访客数和三类图片导出次数。事件使用随机 ID 幂等写入，离线时暂存浏览器并在恢复连接后补报；访客数是匿名标识去重值，不等于实名用户数。
- **隐私边界**：数据库保存完整评选快照用于服务端校验和统计，公开海报接口只返回展示所需字段，不返回完整 JSON 或豆瓣 UID。评选结果和颁奖词可能直接呈现在公开图片中。
- **移动端**：顶部导航在窄屏下独立横向滚动，不再撑宽整个页面。

详细使用规则见 [人人奥斯卡](docs/人人奥斯卡.md)、[奥斯卡](docs/奥斯卡.md) 和 [Top榜](docs/Top榜.md)。

## 快速开始

前端：

```bash
cd app
npm install
npm run dev
```

社区后端（另开终端）：

```bash
cd server
npm install
cp .env.example .env       # Windows 可手动复制该文件
npm run db:migrate
npm run dev
```

浏览器访问 `http://localhost:3000`。Vite 将 `/api/community` 代理到 `127.0.0.1:3100`，豆瓣接口继续使用原有代理。

## 测试与构建

```bash
cd app && npm test && npm run build
cd server && npm test && npm run build
```

前端产物在 `app/dist`，后端编译产物在 `server/dist`。生产部署、Nginx、systemd、数据目录和备份方法见 [部署说明](deploy/README.md)。

本次社区功能已通过前端 6 项测试、后端 4 项集成测试，以及真实 Edge 浏览器的“导出、注册、上传、点赞、统计、覆盖清零”完整流程验收；375 像素移动端视口无整页横向溢出。前端全量 ESLint 仍有 35 项原项目历史问题，本次新增和修改文件的检查已通过。

## 技术栈

- 前端：Vite · React 19 · TypeScript · Tailwind CSS · shadcn/ui · React Router · html-to-image
- 社区后端：Node.js · Fastify · Prisma · SQLite · Zod · Sharp
- 数据：完整版本化评选 JSON + 可查询的统计条目 + 文件系统 JPEG/缩略图
- 标识：评选和图片使用 UUID；JPEG 只在标准 EXIF `ImageUniqueID` 中写入图片 UUID
