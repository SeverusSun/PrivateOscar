# 人人奥斯卡

「人人奥斯卡」用于展示用户主动上传的海报和评选，包含「海报展示」与「众人所评」两个子页面。

## 上传与账号

- 导出奥斯卡海报、完整名单或 Top 榜后，JPEG 会先正常下载，再弹出上传窗口。
- 上传、覆盖、点赞和删除需要网站账号；账号可绑定当前同步的豆瓣 UID。
- 上传前按同一 UID、评选模式、范围、Top 类别（仅 Top 榜）和本次图片类型检测已有结果，上传弹窗会展示这套“检测已有同类型评选”机制。
- 奥斯卡海报与提名名单分别检测。只上传过海报时，首次补充名单不会提示冲突，而是归入同一份评选并保留原海报点赞。
- 「覆盖并清零点赞」会替换当前评选及对应图片，并将旧评选关联海报的点赞全部清零。未被替换的其他类型图片可以保留，但它们的点赞也会同时清零，且无法恢复。
- 「上传唯一评选结果」会保留旧结果，另建一份独立评选，旧图片及其点赞不受影响。
- 公开内容包含用户名和图片；评选结果与颁奖词可能直接呈现在图片中。公开海报接口不返回完整评选 JSON 或豆瓣 UID。

## 海报展示

- 按奥斯卡海报、奥斯卡提名名单、Top 榜筛选。
- 按标记年份（含光影生涯）或上映年份筛选。
- Top 榜可按预设或自定义类别筛选。
- 第二行可按豆瓣用户检索：UID 需要完整精确匹配，显示名支持输入部分文字模糊搜索；公开结果仍不返回 UID。
- 「我的上传」独立位于第三行，只显示当前账号发布的内容，可查看原图并删除自己的评选。
- 支持按点赞量、上传时间正序或倒序排列。
- 海报按原始宽高比采用响应式瀑布流排列，不再统一为固定比例；缩略图使用浏览器原生懒加载与异步解码，并保留宽高以减少布局偏移。
- 每页加载 12 张缩略图，可通过分页继续浏览；点击海报仍可查看和下载原图。
- 每个账号对一张图片最多点赞一次，再次点击可取消点赞。
- 图片 UUID 可复制，原图 EXIF 的 `ImageUniqueID` 中保存相同标识。

## 众人所评

- 奥斯卡模式：逐个列出全部传统、可选及已上传的自定义奖项，只统计最终获奖记录。
- Top 模式：逐个列出每个预设及已上传的自定义 Top 类别，统计所有入榜名次。
- 人物奖项显示人物名与关联电影；普通影片奖项显示电影名。
- 每组按出现次数降序，同次数按片名排序，固定展示前十名；无数据时显示「暂无评选记录」。

## 站点统计

页面显示累计匿名访客数，以及奥斯卡海报、完整名单和 Top 榜的成功生成导出次数。访客按浏览器中的匿名随机标识去重，不等于注册用户数或精确自然人数。离线事件会暂存浏览器并在恢复连接后补报，重复事件不会重复计数，但未联网期间的数据可能延迟出现。
