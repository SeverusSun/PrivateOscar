# 评选界面

全站的核心：举办你的私人奥斯卡，或排出 Top N 片单。

## 顶部：评选模式与范围

**评选模式**（二选一）：`奥斯卡` / `Top 榜`。

**评选范围**：
- **标记年份**：按你何时记录词条来圈定参评影片。
  - `光影生涯`：从全部「看过」影片中评选；
  - 或选择具体某一年。
- **上映年份**：按影片上映年份圈定（列表下拉选择，仅单年，无「光影生涯」）。

切换范围需**连点两次确认**，因为会清空所有提名与获奖（含 Top 榜名次），防止误触丢失进度。

## 奥斯卡模式

### 奖项池
- **传统奖项（17 项）**：最佳影片、最佳导演、男女主配、剪辑、摄影、视效、音效、配乐、服化道、最佳动画等，默认开启，可单独或整体开关。
- **可选奖项（21 项）**：最感动、最震撼、最爽、最低估、最过誉、最不认同、最看不懂、最前卫、最失望、最惊喜、最期待等，置首的 6 项（文曲星、武状元、最爱导演、最爱男演员、最爱女演员、最佳海报设计）默认开启，其余按需勾选。
- **自定义奖项**：输入自定义类别（如：纪录片 / 斯坦利·库布里克 / 法国新浪潮 / 20 世纪），可添加多个、单独开关或删除。

所有奖项卡片左侧的 ⠿ 支持**拖拽排序**，顺序与海报同步。

### 给奖项评选
1. 「**选择提名影片**」打开勾选弹窗：只列出当前范围内的「看过」影片（「最期待」例外，从「想看」中提名），弹窗内同样支持豆瓣评分区间与我的星级筛选；顶部的「**未定**」勾选后其他影片置灰。若搜索不到想提名的影片，点空结果下方的「**手动同步电影词条**」可直接补录（搜索词自动带入，补录后即可提名）。
2. 勾好提名后，在每个提名上「**设为获奖**」定下最终得主。
3. 标题行的「**获奖未定**」开关：开启后不必选出获奖者（"都很强，选不出来"），已设获奖自动取消。
4. 「**颁奖词**」：为获奖填写感言。未手写时自动回退显示（优先级：文本输入 > 电影短评 > 奖项说明）。填写后按钮变绿。

### 人物奖项
最佳导演、最爱导演、男女主角、男女配角、最爱男女演员、最佳海报设计属于人物类奖项：
- 「**上传图片/简介**」中可手动填写姓名、上传照片与简介；
- 「**从主演中选择**」下拉会列出该影片的**前 6 位演员**，选中后自动从豆瓣拉取该演员照片；导演奖项不填姓名时自动取第一位导演的照片。

### 进度
页面顶部的进度条实时反映每个奖项的状态（已评出 / 获奖未定 / 提名未定 / 待评选）。

## Top 榜模式

- 选择 **Top N**（5 / 10 / 20 / 自定义）与 **Top 类别**（最佳 / 最爱 / 导演 / 男演 / 女演 / 战争 / 歌舞 / 同性 / 动画 / 悬疑等，或自定义类别）。
- 每个名次「选择影片」（同样带评分筛选），左侧 ⠿ **拖拽**可将一部影片拖到另一名次，两部电影交换位置。选片浮窗搜不到影片时，同样可在空结果下方「手动同步电影词条」补录。
- 每个名次可写「颁奖词」、上传图片/简介；「男演 / 女演」类别同样支持「从主演中选择」。
- 进度条按名次着色：已评出 = 深绿。
