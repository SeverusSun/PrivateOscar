# 同步界面

把你的豆瓣书影音档案一键搬到本站，是使用的起点。

## 如何同步

1. 在输入框粘贴**豆瓣用户 ID 或主页链接**（如 `https://www.douban.com/people/你的ID/`），支持纯 ID、people 链接、域名空间链接三种格式。
2. 可选：勾选同步按钮旁的「**包含动画/剧集**」。默认只同步电影词条；勾上后会同时同步动画、剧集类词条（如《新世纪福音战士》《隐秘的角落》）。
3. 点「开始同步」，自动抓取你标记过的全部词条，进度条实时显示数量。

## 同步下来的内容

每个词条包含：电影海报、电影名、导演、简介、豆瓣评分、**你的记录时间**（何时标记）、你的打分、短评，以及尽力同步的长篇影评。

> 同步走豆瓣公开接口，只读取你账户**公开**的书影音档案；豆瓣请求经同源代理转发，同步结果只写入你自己的浏览器 localStorage，不会自动保存到社区数据库。只有之后主动上传的海报和评选才会进入「人人奥斯卡」。

## 手动补录（同步遗漏的影片）

若某些影片在自动同步中缺失（多见于极早期标记的条目），可手动补录：

1. 在「影库」界面视图按钮下方点「**手动同步电影词条**」，或在评选/Top 榜的选片浮窗搜不到影片时，直接点空结果下方的同名按钮（搜索词自动带入）。
2. 输入**片名或导演名**点「预览」，浮窗会从豆瓣网页搜索返回相关词条（片名、年份、导演演员、豆瓣评分），已在影库的条目置灰。
3. 勾选后点「**同步**」即可加入影库（标记为「看过」，记录时间为补录当天），可直接参与评选。

> 提示：在评选界面的选片浮窗内补录，适用于「光影生涯」或补录当年；标记年份口径下影片归属按记录时间计算。

## 同步完成后

- 账户卡片显示头像、昵称与统计（共 N 部 · 看过 / 在看 / 想看）。
- 账户右侧的「**清空同步数据**」按钮（需连点两次确认）会删除本站全部本地数据：影库、评选结果、Top 榜、海报自定义设置与演职员缓存，恢复默认。

## 常见问题

**Q：同步数量比豆瓣显示的少？**
豆瓣「全部」计数包含你标记后已被豆瓣删除或合并的条目。本站在抓完全部翻页后，还会通过网页版档案补扫一遍移动端接口遗漏的条目；极早期标记的条目如仍缺失，可用「手动同步电影词条」补录（见上文）。

**Q：为什么关浏览器再打开还是已同步状态？**
数据保存在浏览器 localStorage，关闭浏览器不会清除，保存评选结果方便用户中断后继续填写。换浏览器、换设备或清空站点数据后需要重新同步。
