# 影库界面

浏览、筛选和管理同步下来的全部词条。

## 视图与状态

- **卡片 / 列表**两种视图模式（记住上次选择）。
- 顶部标签：**全部 / 看过 / 在看 / 想看**。
- 搜索框：按**片名 / 导演**关键词过滤。

## 多重筛选

以下条件可叠加（AND 关系）：

**① 年份（二选一）**
- **标记年份**：按你何时记录该词条筛选（对应豆瓣档案中的标记时间）。
- **上映年份**：按词条的上映年份筛选。

同一时间只能启用其中一种口径。

**② 豆瓣评分区间**
| 档位 | 区间 |
|---|---|
| 烂片 | 7 分以下 |
| 及格 | [7.0, 7.4] |
| 中规中矩 | (7.4, 8.0) |
| 优秀作品 | [8.0, 8.8) |
| 神作 | [8.8, 10] |

**③ 我的星级**：一到五星，以及「未评」（含豆瓣评分缺失的条目）。

## 手动同步电影词条

视图按钮下方的「**手动同步电影词条**」按钮用于补录自动同步遗漏的影片：输入片名或导演名点「预览」从豆瓣检索，勾选后「同步」入库（标记为「看过」，记录时间为补录当天）。详见 [同步的手动补录](同步.md#手动补录同步遗漏的影片)。

## 词条详情

点开任意词条可查看完整信息，并可以：
- 手动修改**我的评分**（影库内修改会同步到评选与海报）；
- 补写/修改**短评**；
- 同步失败时**手动粘贴长篇影评**；
- 查看海报、简介、豆瓣评分、标记时间与导演。
