# 关于界面

站点信息汇总，所有卡片默认折叠，点击左侧小三角展开。

- **关于本站**：项目简介与 GitHub 仓库地址（github.com/SeverusSun/PrivateOscar）。
- **关于作者**：作者「秋菊十二」的豆瓣 ID、GitHub 主页与打赏二维码。
- **功能一览**：七大界面功能速览。
- **数据与隐私**：本地优先说明——影库与评选进度默认仅保存在浏览器 localStorage；只有主动上传的数据才会公开。公开海报接口不返回豆瓣 UID 或完整评选 JSON，但评选结果和颁奖词可能呈现在公开图片中。
- **社区账号**：上传、覆盖、点赞和删除使用网站账号及 HttpOnly Cookie 会话；社区账号不会自动同步浏览器里的私人影库。
- **站点统计**：累计访客按浏览器中的匿名随机标识去重，不等于实名用户数；导出事件离线补报时可能延迟显示。
- **技术说明**：前端、Fastify 社区后端、Prisma + SQLite、版本化评选 JSON 与 JPEG EXIF UUID 等实现要点。
- **免责声明**：海报等内容的版权说明。
