# 奥斯卡界面（海报导出）

把评选结果导出成两张海报：**私人奥斯卡主海报** 与 **完整名单海报**。

## 私人奥斯卡主海报

- 每个奖项一张卡片：奖项名 + 获奖海报图 + 片名/导演 + 豆瓣评分 + 我的星级（星级用实心/描边 SVG 星星表示，未评显示五颗描边星）。
- 「未定」的奖项显示奖杯剪影占位。
- **一行两个 / 四个 / 六个**三种排版（六个时整幅加宽）。
- 报头开关：**小金人**、**豆瓣头像**（默认开）、**仅显示电影名**（开启后卡片只留奖项名、图和片名，卡片同步缩窄）。
- 标题/副标题可自定义（默认「用户名 年份[上映] 私人奥斯卡」，`上映` 二字仅在上映年份口径时出现）。

## 完整名单海报

- 纯文字版：每个奖项列出**最终获奖（烫金色 👑）**与**全部提名（墨绿色）**，仅含片名、豆瓣评分、我的星级。
- 右侧附颁奖词。
- 导演/演员类奖项不重复显示影片导演信息。

## 导出选项（两张海报通用）

- **格式**：JPEG。每张图片使用 32 位小写十六进制 UUID，并且只在标准 EXIF `ImageUniqueID` 中写入该图片 UUID；不再向 EXIF 写入用户名、评选范围等业务数据。
- **导出清晰度**：1x / 2x / 3x。
- **三行文字样式控制**：标题/副标题、奖项名/电影信息、颁奖词，每行可独立调整**字体**（支持枚举本机全部字体）、**字号**、**文字颜色**。

> 海报由 DOM 离线渲染导出：豆瓣图片先经本地代理转为同源再绘制，避免跨域污染画布。

## 导出后上传到人人奥斯卡

1. 主海报或完整名单成功生成后，JPEG 会先下载到本地，再弹出上传窗口；关闭窗口不会自动上传。
2. 上传需要登录网站账号，账号绑定的豆瓣 UID 必须与当前同步账户一致。
3. 上传前按相同 UID、评选范围和本次图片类型检测，弹窗会显示完整检测机制。主海报与提名名单分别检测，只上传过主海报不会阻止首次补充名单；补充图片归入同一份评选并保留原海报点赞。覆盖前会明确提示旧评选所有关联海报的点赞将全部清零；也可选择「上传唯一评选结果」另建独立结果。
4. 上传成功后可到「人人奥斯卡」筛选、查看或点赞；在「我的上传」中可删除自己的整份评选及其关联图片。

完整覆盖规则、点赞和统计说明见 [人人奥斯卡](人人奥斯卡.md)。
