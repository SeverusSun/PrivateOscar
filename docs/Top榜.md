# Top榜界面（榜单导出）

把「评选」页排出的 Top N 片单导出成一张榜单图片。

## 前提

请先在「**评选**」页切换到 Top 榜模式完成评选，再回到本界面导出。

## 榜单内容

- 每个名次一行：名次 + 影片海报缩略图 + 片名 + 豆瓣评分 + 我的星级（未评为描边空心星）。
- **前三名金银铜色调**开关（默认开启）：前三名名次使用金 / 银 / 铜三色；关闭后所有名次统一为烫金色「TOP n」文字。
- 报头开关：**小金人**、**豆瓣头像**（默认开）。
- 标题 / 副标题可自定义（默认「用户名 年份[上映] Top N 类别」，上映年份口径会带「上映」二字）。
- 「导演」类别的名次自动匹配导演照片展示；「男演 / 女演」类别在评选页上传图片/简介时同样支持从主演中选择并自动拉取照片。
- 每个名次的颁奖词在评选页填写，标题/信息/颁奖词三行文字样式（字体、字号、颜色）可在本界面独立调整。

## 导出

- **格式**：JPEG。每张图片使用 32 位小写十六进制 UUID，并且只在标准 EXIF `ImageUniqueID` 中写入该图片 UUID；不再向 EXIF 写入用户名、Top 类别或评选范围等业务数据。
- **导出清晰度**：1x / 2x / 3x。
- **导出后上传**：图片先下载到本地，再弹出上传窗口。登录与当前豆瓣 UID 绑定的网站账号后，可主动上传到「人人奥斯卡」。
- **重复评选**：相同 UID、范围和 Top 类别下已有结果时，可选择「覆盖并清零点赞」或「上传唯一评选结果」。覆盖会清除旧评选所有关联海报的点赞；独立上传会保留旧结果及其点赞。

上传后的分类筛选、点赞和各 Top 类别前十名统计见 [人人奥斯卡](人人奥斯卡.md)。
